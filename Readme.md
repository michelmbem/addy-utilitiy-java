# Addy Common Java Utilities
A general purpose utility class library for the Java platform by Addy.

These include:

* **StringUtil**: A collection of helper methods for string manipulations.
* **FileUtil**: A collection of IO related helper methods.
* **DateUtil**: A collection of helper methods for date and time manipulations based on *java.util.Date* and *java.util.Calendar*.
* **ArrayUtil**: A collection of helper methods for array manipulations.
* **CollectionUtil**: A collection of helper methods for collection manipulations.
* **ObjectUtil**: A few helper methods for generic objects manipulations.
* **ExceptionUtil**: A few helper methods for extracting values from throwables.
* **ImageHelper**: A collection of helper methods for cropping, resizing, rotating, flipping images and more.
* **VideoHelper**: A collection of helper methods for manipulating video files.
* **PDFHelper**: A helper class that supplies methods for creating or manipulating PDF files.
* **JRHelper**: A helper class that eases interaction with the *JasperReports* library (optional dependency).
